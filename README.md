# Las Alitas Mix · página de demostración

Página estática de demostración de diseño y animaciones. Sin dependencias.

## Ver en local
```
python3 -m http.server 8080
```
Abrir http://localhost:8080

## Editar datos
Precios, salsas por combo, WhatsApp y horarios están en `js/config.js`.

## Publicar en GitHub Pages
Subir el repositorio y activar Settings → Pages → Deploy from branch → `main` / raíz.

## Nota
Demostración de diseño. No es el sitio oficial de Las Alitas Mix.
